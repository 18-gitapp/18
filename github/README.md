# github/ — دستورهای رانر گیت‌هاب (مثل مراحل فایل yml)

هر پوشه یک **مرحله‌ی جدا** توی workflow هست و `*.sh`هاش به ترتیب نام اجرا میشن. همه‌ی Secretها متغیر محیطی‌ان
(از جمله `GH_TOKEN` و `NEXT_REPO`)، و `GITHUB_TOKEN`، `GITHUB_REPOSITORY` و بقیه‌ی متغیرهای استاندارد Actions هم هستن.

| پوشه | کی؟ |
|---|---|
| `pre/` | قبل از فاز لینوکس |
| `post/` | بعد از فاز لینوکس (اگه Cancel نشده باشه). ماژول تحویل به اکانت بعدی اینجاست: `post/10-handoff.sh` |
| `always/` | همیشه، حتی اگه چیزی خراب شد |

یادداشت: چیزهایی که `uses:` می‌خوان (مثل checkout یا آپلود Artifact) توی خود `runner.yml` هستن.
اگه `github/post/10-handoff.sh` رو حذف کنی، شیفت تموم میشه و تمام (هیچ اکانتی بعدش اجرا نمیشه).
